# Changelog

## Windows studio 0.1.0 — 2026-11-12

- Added a React/Three.js browser studio and portable Electron app with a dedicated OBS capture window, one webcam owner, and keyboard controls.
- Added 20 adjustable GPU effects plus Original, prewarmed shaders, adaptive quality, bounded GPU frame history, and person/background composition.
- Added local MediaPipe hand and person-mask workers, opt-in microphone confirmation, PNG and video recording, and a device-free DEMO.
- Added ten GPU transition styles, reduced-flash controls, and a saved editable effect rotation.
- Added strict validation, Chrome and Electron integration checks, and per-effect benchmark and regression reports.
- Published Windows setup, OBS acceptance, architecture and licensing documentation alongside the existing TouchDesigner project.

## 0.2.0 — 2026-11-12

- Added the full 21-style GPU catalog, 11 transition presets, accessibility controls and a reference-inspired DEMO showcase.
- Added a local OSC gesture bridge, snap worker, audio confirmation, calibration, and a standalone synthetic event sender.
- Added the performance panel, effect and playlist controls, local configuration, source fallbacks, clean output, screenshots, and sequence or Motion JPEG capture.
- Saved `SnapReality.toe` from TouchDesigner and recorded native validation.

## 0.1.0 — 2026-11-11

- Added the animated DEMO source, five effects, SNAP transition and Perform Mode controls.
- Saved and reopened the first native TouchDesigner checkpoint under `checkpoints/`.
